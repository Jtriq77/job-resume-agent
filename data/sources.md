# 数据来源与许可（提交前请保留）

## 1. 岗位数据

| 项 | 内容 |
|---|---|
| 名称 | job_radar / jobsearchradar |
| 仓库 | https://github.com/lijiaqi-AI-Product-Manager/job_radar |
| 数据快照 | `2026-11-23T01:53:40Z`（北京时间 11-23 09:53） |
| 规模 | 360,178 条岗位；314,384 条可见；2,172 家公司；JD 覆盖 97.6% |
| 代码许可 | MIT |
| 内容许可 | 招聘文本与来源站点内容的权利归原权利人；项目只做公开索引，不绕过登录/验证码；代码许可不构成对第三方内容的额外授权 |
| 本项目用途 | 课程研究：岗位族分类、匹配排序、三档链接演示；不转售、不批量再分发 |

## 2. 抽样

| 项 | 值 |
|---|---|
| 文件 | `data/jobs_sample.jsonl` |
| 总量 | 3,900 条 |
| 类别 | 13 类 × 300 条（技术、产品、运营、设计、市场销售、职能、金融、医药、工程制造、管培、项目管理、教育培训、其他） |
| 类型 | 校招 70% / 实习 30%（部分类别实习不足，用校招补） |
| 抽样 | 类别内按 `md5(seed:job_id)` 排序取前 N，seed=42，可复现 |
| 过滤 | 必须存在 JD 正文（description/requirements 合计 > 20 字） |
| 标签 | 来自 job_radar 的规则职类，**不是人工金标准** |
| 报告 | `data/sampling_report.json` |

## 4. 公司分层

| 文件 | `data/companies.csv` |
|---|---|
| 分层 | 大厂 / 中厂 / 小厂，各 10 家 |
| 依据 | 校招规模、品牌知名度、公开规模信息；主观划分 |
| 免责声明 | 不代表公司优劣，不构成求职建议；仅用于投递节奏（冲刺/匹配/保底） |

## 5. 不使用 / 不做

- 不爬 BOSS 直聘、领英等需要登录/验证码的页面；
- 不批量再分发 job_radar 全库；
- 不把岗位内容当成已核实资格；
- 不做真实自动投递。
