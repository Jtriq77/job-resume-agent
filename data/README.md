# 数据说明

仓库保留：

- `jobs_sample.jsonl`：3,900 条分层岗位样本；
- `jobs_linked.jsonl`：30 条带链接演示岗位；
- `link_status.csv`：链接检查结果；
- `companies.csv`：公司分层；
- `gold_300.csv`：300 条人工金标准模板（标签待人工补全）；
- `ranker_pairs.csv`：2,600 对弱标注排序样本；
- `job_clusters.csv`：3,900 条岗位聚类结果；
- `template_audit.csv`：497 份模板体检结果。

没有进入仓库：

- `data/_raw_jobradar/` 原始 1G 数据库；
- `data/profile.json`、`data/output/`、`data/applications.csv` 等个人数据；
- 291M 全量模板库（仅保留 21 个代表模板）。
