# 简历模板：已选与使用说明

## 1. 筛选结果

从课程模板集合的 **497 份 DOCX** 中，按页数、表格、文本框、分栏、区块完整度、字数、文件名方向做了批量体检，结果在 `data/template_audit.csv`。

### 主模板

**`01_主模板_产品运营_单页_可填充.docx`**

| 指标 | 值 |
|---|---|
| 页数 | 1 |
| 分栏 | 1 |
| 表格 | 0 |
| 文本框 | 0 |
| 正文字数 | 2,239 |
| 区块 | 教育 / 实习 / 校园 / 技能等 8 个 |
| 来源 | `templates/gallery_raw/大厂实习简历4.docx` |

理由：单页、单栏、无表格/文本框，ATS 解析最稳；版式干净，适合数据/产品/运营方向。

### 模板库

- `templates/gallery.json`：21 个代表模板的元数据（页数、表格、文本框、分栏、区块、标签、预览、下载路径）；
- `templates/previews/`：12 张首页缩略图；
- App 的「📄 简历模板」页支持搜索、按页数/版式/类型筛选、下载原 DOCX；
- 只有主模板接入一键生成；其余模板是“可下载原文件编辑”，不是“可一键填充”。

完整清单仍以 `data/template_audit.csv` 为准。

### 为什么没选更花哨的

- `精选单页简历模板46.docx`：体检分高，但表格版、实际 2 页、版式偏旧；
- 很多两栏/文本框模板：机器填充容易错位，ATS 解析差；
- 多页套装（封面+自荐信+尾页）：不适合校招单页投递。

## 2. 可填充主模板

`01_主模板_产品运营_单页_可填充.docx` 已把样例文字替换成占位符，样例照片替换成 `PHOTO` 占位图，避免使用模板里别人的照片。

占位符示例：

```
{{name}}  {{job_intent}}  {{contact}}
{{edu1_date}} {{edu1_school}} {{edu1_major}} {{edu1_degree}}
{{int1_date}} {{int1_company}} {{int1_dept}} {{int1_role}}
{{int1_b1}} ...
{{cam1_date}} {{cam1_org}} {{cam1_role}}
{{skill1}} {{skill2}} {{skill3}}
```

槽位与动态扩展：

- 模板自带 2 段教育、2 段实习、2 段校园的原型；
- 第 3 段及以后由 `build_resume_from_profile.py` 自动复制第 2 段段落块，用户说几段就写几段；
- 不截断、不为省一页删内容；段数多时允许 2 页；
- 画像更新后旧 Docx 不自动替换，App 会隐藏旧下载并要求重新生成；
- 技能仍按“语言/工具/证书”三行归并，不会丢技能。

## 3. 生成示例

```bash
# 用虚构画像填充主模板
python scripts/build_sample_resume.py
# 输出 examples/sample_resume_产品运营.docx（1 页）
```

或在 App 的「📄 简历模板」页点「用示例画像生成一份简历」。

示例画像在 `examples/sample_profile.json`，是虚构数据，不是真人。

## 4. 你自己的模板

如果你更想用别的模板：

1. 放进 `templates/`；
2. 告诉我文件名；
3. 我先跑 `python scripts/audit_templates.py` 体检，再决定是否值得接。

如果模板是 PDF/图片，需要先重建成 DOCX；我可以做，但会多花时间。
