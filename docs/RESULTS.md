## 2. 岗位族分类（TF-IDF + MultinomialNB）

| 项 | 值 |
|---|---|
| 模型 | 字符 1–3 n-gram + 英文 token；TF-IDF；多项式 NB；alpha=0.3；max_features=30,000 |
| 训练/测试 | 3,120 / 780（分层 80/20，seed=42） |
| Accuracy | **0.7615** |
| Macro-F1 | **0.7602** |
| Weighted-F1 | 0.7602 |
| 多数类基线 Macro-F1 | 0.011 |

### 消融

| 配置 | Macro-F1 | 说明 |
|---|---|---|
| 标题 + 正文（主模型） | 0.7602 | 部署用 |
| 只用标题 | 0.9244 | **高分段主要来自标签与标题规则同源，存在泄漏，不能当泛化结论** |
| 多数类 | 0.011 | 说明类别不平衡基线很弱 |

### 结论与限制

- 工程制造、管培、运营、市场销售最弱；主要混淆在产品/运营、技术/工程制造。
- 当前指标是**银标准**：标签由 job_radar 的标题规则生成，不是人工标注。
- 需要 300 条人工金标准复核；否则不能声称 0.76 是真实泛化性能。
- 标题-only 0.924 是泄漏信号，不是模型更强。

## 8. 岗位聚类（TF-IDF + spherical K-Means++）

| k | 轮廓系数 | 纯度（解释用） |
|---:|---:|---:|
| 6 | 0.0543 | 0.3115 |
| 8 | 0.0638 | 0.3826 |
| 10 | 0.0617 | 0.4641 |
| **13** | **0.0656** | **0.4564** |

- 选择 k=13；输出 `models/job_kmeans.pkl`、`data/job_clusters.csv`；
- 轮廓系数偏低：岗位 JD 用词重叠大、短文本噪声多，簇边界模糊；
- 聚类是无监督探索，不替代有监督岗位族分类。

## 9. 简历–岗位排序（7 维特征 + L2 逻辑回归）

| 指标 | 逻辑回归 | 技能覆盖基线 |
|---|---:|---:|
| NDCG@5 | **0.8543** | 0.5839 |
| NDCG@10 | **0.8572** | 0.5742 |
| Recall@5 | **0.3320** | 0.0458 |

- 2,600 对弱标注（5 个虚构画像 × 每族 40 条）；
- 标签只按岗位族生成，**不是人工相关性标注**；
- 曾因 `category_match` 特征导致 NDCG=1.0 的标签泄漏，已移除并重跑；
- 产物：`data/ranker_pairs.csv`、`models/job_ranker.json`。
