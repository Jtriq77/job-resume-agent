# 补充信息测试：上海市奖学金（2026-11-24）

## 问题

先输入完整画像，再补一句“我有上海市奖学金”。

- 模型对这句只返回空四段；
- 合并时没有字段承接“奖学金”，于是这句話丢失；
- 生成的 DOCX 里没有上海市奖学金。

## 原因

“奖学金”不在四段 schema 的独立字段里；单句补充没有学校/专业，模型不会新建教育条目，也不属于实习/项目/技能。

## 修复

`src/agent/profile_extract.py` 增加 `apply_supplement`：

- 奖学金 → 最高学历教育的 `extra`（荣誉行）；
- 竞赛/比赛 → `campus`；
- 技能词 → `skills`；
- 日期区间 → 补到没有日期的实习；
- 竞赛不再错误继承实习日期。

同时 App 增加画像哈希：补充后旧 DOCX 隐藏并删除，必须重新生成。

## 验证

- 初始教育荣誉：`多次获得校内奖学金、国家奖学金`
- 补充后：`多次获得校内奖学金、国家奖学金；上海市奖学金`
- 生成的 `data/output/简历_林晓.docx` 中包含：
  `- GPA：3.8；多次获得校内奖学金、国家奖学金；上海市奖学金`
- 实习日期：`2025.03-2025.08`、`2025.09-2026.01` 正确补到两段实习；
- 竞赛日期保持为空，没有被实习日期污染。
